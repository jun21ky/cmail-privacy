# Cmail

**Cmail** は、開発者が自分のために作っている Mac 用のメールクライアントと、そのコマンドラインツール（`cmail`）です。一般には配布していません。

- Gmail のメールを読み、要約・翻訳し、返信の下書きを作ります
- ラベルの付け替え・アーカイブ・フィルタの管理など、受信トレイの整理を手伝います
- **メールを送るのは、必ず本人が内容を確認したあとだけです。** AI が書いた返信を自動で送ることはありません

プライバシーポリシー: [privacy](privacy.html)

## Cmail (English)

Cmail is a personal Mac mail client and command-line tool built by its developer for their own use. It is not distributed to the public. It reads Gmail messages, summarizes and translates them, drafts replies, and helps organize the inbox (labels, archiving, filters). Mail is only sent after the user has reviewed it; AI-written replies are never sent automatically.
